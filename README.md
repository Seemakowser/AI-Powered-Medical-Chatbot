# AI-Powered Medical Chatbot for Heart Disease Detection

## Overview

This project demonstrates the integration of Artificial Intelligence and healthcare by using a Hugging Face Vision Transformer (ViT) model to analyze medical images and provide preliminary heart disease-related insights.

## Features

* Medical image upload
* AI-based image classification
* Healthcare recommendations
* Gradio web interface
* Google Colab implementation

## Technologies Used

* Python
* Hugging Face Transformers
* PyTorch
* Gradio
* Google Colab

## Project Structure

* AI_Powered_Medical_Chatbot.ipynb

* Screenshots
* README

This project is developed for educational and internship purposes only and is not intended for actual medical diagnosis.
